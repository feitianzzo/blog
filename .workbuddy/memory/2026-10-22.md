# 2026-10-22

## 博客站点（新博客项目）

- 从零搭建了一个带后台的博客：Node 22 + Express 4 + multer，数据用 `data/db.json` 文件存储（无数据库依赖）。
- 结构：`server.js`（接口/上传/静态）、`lib/store.js`（数据读写与种子内容）、`lib/auth.js`（scrypt 密码、HttpOnly Cookie 会话、登录限流、会话落盘到 `data/sessions.json`）。
- 前端三页：`public/index.html`（列表）、`public/post.html`（详情，路由 `/p/:id`）、`public/admin.html`（登录 + 列表 + 编辑器）。
- Markdown 渲染器是自己写的 `public/assets/md.js`（无第三方依赖，先转义再解析，防 XSS）。支持标题/列表（含一级嵌套）/引用/代码块/表格/链接图片/hr。
- 设计语言：米色纸感背景 `#fbfaf7`、墨色文字、赭红强调色 `#a84a2c`、衬线标题（Noto Serif SC 系列）+ 无衬线正文；桌面双列卡片、移动端单列。
- 默认账号 admin / admin123，首次启动生成 `data/auth.json`；可用 `BLOG_USER` / `BLOG_PASS` 覆盖。

### 踩过的坑

- `.login { display:flex }` 覆盖了 UA 的 `[hidden]` 规则，导致登录页和后台同时渲染 → 全局加 `[hidden] { display: none !important }`。
- 首页卡片有/无封面时高度不齐 → 统一保留 16:9 媒体区，无封面用同色渐变 + 首字占位。
- 移动端编辑器曾把封面面板 `order:-1` 顶到最前，书写区被挤到屏幕外 → 改回自然顺序。
- 中文项目目录名会让 `npm init` 报 Invalid name，手写 package.json 绕过。

### 验证方式

- 用 Chrome DevTools Protocol（Node 内置 WebSocket）写脚本截图 + 驱动交互，验证了登录、发文带封面上传、前台展示、编辑、草稿隐藏、删除。工具脚本在系统 temp 目录，未放进项目。
- 服务默认端口 4173，`npm start` 启动。
